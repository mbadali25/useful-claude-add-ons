The Crew Plugin: Technical Reference

Generated from useful-claude-add-ons@541b2b70 on 2026-09-22. Verify before trusting.
The low-level guide, for the people who install, configure and extend crew. A companion overview covers the same ground in plain language. Written against crew 0.20.11 on post-207-checklist, commit 541b2b70.

Design constraint. A role earns its place only if it buys one of three things: an isolated context window, a restricted tool set, or genuinely independent eyes. Everything else is a file, a command, or the user. Every custom subagent loads the entire CLAUDE.md hierarchy at startup, so the roster is kept small and the knowledge is kept in files.

The PM

Always spawned as a plain subagent with no name — a named spawn becomes an addressable teammate, and per agent teams teammates cannot spawn their own teammates, which would break its whole job of dispatching roles. Tools: Read, Write, Edit, Bash, Grep, Glob, Agent, Skill. No SendMessage, no ListAgents, so resume-by-id belongs to the caller (commands/pm.md): within a session it resumes the held agent id via SendMessage to that id; across sessions it reads .crew/pm-standing.md in full (durable decisions and vetoes) and the tail of .crew/pm-journal.md (dated per-turn entries), both appended only through hooks/scripts/pm_journal.py --append (the caller Writes the entry to .work/pm-entry.md, and the script moves those bytes with no shell in the path), never a heredoc, Write, or Edit directly against either file. Authority is report-only | act | autonomous; the stops in crew_state.AUTONOMOUS_STOPS hold at every tier: offboarding a role, deleting a codemap or diagram, rewriting .crew/metrics.md, destroying git history. Dispatch cap 3 per pass. Write scope: .crew/**, TODO.md, .work/**, docs/diagrams/**, enforced by the role write guard. Since agents/pm.md's most recent change, the PM re-reads full crew_state.py output plus HEAD, branch and git status --porcelain before every dispatch, and on every return runs rev-parse, merge-base --is-ancestor, log <pre>..HEAD and branch --show-current against its own checkout, so a backward, sideways or foreign-forward HEAD is reported rather than assumed away.

Model Routing

crew_config.py --models prints the effective provider, model and family per role, which fallbacks are armed, and whether the self-review guard bars anything. The QA order tries Codex first, then a Copilot model, then Claude; a reviewer of the same family as the diff's author is struck (qa.order walked by family, never a fixed list of three names). Config keys dev.roles.*, qa.roles.*, dev.fallback, qa.fallback, both open tables so an unlisted role is still settable. The Agent tool's model override applies per dispatch.

6. The Stop Gate and the PM: Crew 0.20.11

The current top entry in CHANGELOG.md's [Unreleased] section, filed against crew 0.20.11, closes three related defects in one pass.

Evidence Retention on a Partial Failure

verify-gate.sh used to exit above the point where it synced the per-rule record, so one failing command discarded every rule that had already passed that turn. The sync now runs first; a failing rule's own outcome is deliberately still not recorded under its own key, because recording it there would orphan the marker the moment the rule is edited to fix it.

The Git Bash python3 Landmine

The gate builds a python3 shim from the proved resolver only when python3 itself is genuinely absent, never shadowing a python or py that is already on PATH; it accepts a native C:\...\python.exe interpreter path, and fails closed with a remediation hint when nothing resolves. context-watch.sh, pm-brief.sh and platform-sync.sh now go through the same strict resolver (crew_py_strict), which requires the probed path to be executable, strips a trailing CR, and normalises drive-letter paths. context-watch.sh specifically: honours stop_hook_active before anything else, fails closed on a stub interpreter without claiming the shared handoff marker (so the PowerShell twin's real budget warning is never suppressed by a false alarm), honours context.enabled: false without needing python at all, and keeps the input's own cwd ahead of CLAUDE_PROJECT_DIR.

The PM's State Going Stale Mid-Pass

agents/pm.md now re-reads full crew_state.py output plus HEAD, branch and git status --porcelain before every dispatch, and on every return runs rev-parse, merge-base --is-ancestor, log <pre>..HEAD and branch --show-current on its own checkout, so a backward, sideways or foreign-forward HEAD is reported instead of assumed unchanged.

render.sh

Handles flags in any position; exits 1 on an empty diagram directory and 2 on contradictory flags; renders to a temporary file so a failed re-render never overwrites the last good output; prints separate ok / skipped / failed counts. Both render scripts (.sh/.ps1) are now tracked executable.

Every hook and script change in this entry carries a must-block/must-allow case that was sabotage-tested on Linux; the agents/pm.md prose change has no automated test of its own, and the new .ps1 resolver cases skip where no PowerShell host exists.

8. Known Items on the Fix List

  • .crew/verify.json has no rule naming test_scope_report.py, test_scope_discipline.py or test_scope_base.py by path, and none whose declared paths cover hooks/scripts/scope_report.py or scope_base.py beyond the whole-suite catch-all rule — a regression in the scope layer alone is not caught until that rule's own trigger fires.
  • The four docs/guides/*.html guides (this document among them) have no committed test binding the shipped files to crew-house-style's HTML route beyond the skill's own prose; a hand edit dropping the print rules or the brand stylesheet would not be caught by anything in plugin/crew/tests/.
  • Regenerating a guide's .docx from its HTML still needs a page-setup and table-width post-processing pass — LibreOffice's HTML-to-OOXML import emits Letter/A4 and margins inconsistently and writes each table's width as an absolute twip value rather than a percentage of the text column — and that pass lives in no committed script in this repository.
  • crew-house-style/SKILL.md's citations into resolve_brand.py (:78-82, :317, :66-67, :298-317, :301) were hand-verified correct at this commit, but the committed drift test covers only the two citations into build_report.py in the same section, so the same kind of line-number rot that has hit other citations in this repository would go unnoticed here.
  • plugin/crew/tests/sabotage.py reports one mutation, in the frozen-artifact path, that goes STILL GREEN under a full run on this Linux host with no identified skip condition explaining it away as a missing interpreter.
