The crew plugin: technical reference

The low-level guide, for the people who install, configure and extend crew. A companion overview covers the same ground in plain language. Written 20 September 2026 against crew 0.19.92 on main (commit 621d50dc); the Stop-gate fix (0.19.93) is described as it stands on branch crew-stop-gate-record at b6e8c4bb, in review.

Design constraint. A role earns its place only if it buys one of three things: an isolated context window, a restricted tool set, or genuinely independent eyes. Everything else is a file, a command, or the user. Every custom subagent loads the entire CLAUDE.md hierarchy at startup, so the roster is kept small and the knowledge is kept in files.

The PM

Standing teammate named crew-pm, reached by SendMessage so it keeps its transcript. Tools: Read, Write, Edit, Bash, Grep, Glob, Agent, Skill. No SendMessage, no ListAgents, so resume-by-id belongs to the caller (commands/pm.md). Authority is report-only | act | autonomous; the stops in crew_state.AUTONOMOUS_STOPS hold at every tier: offboarding a role, deleting a codemap or diagram, rewriting .crew/metrics.md, destroying git history. Dispatch cap 3 per pass. Write scope: .crew/**, TODO.md, .work/**, docs/diagrams/**, enforced by the write guard from 0.19.92.

Model routing

crew_config.py --models prints the effective provider, model and family per role, which fallbacks are armed, and whether the self-review guard bars anything. 7. The Stop gate: 0.19.93 in review

Root causes, measured 19 September

  • verify-gate.sh diffs against .crew/.verify-verified-at, written by record_verified only when DEFERRED_COUNT == 0. rules[8] (185 s) against verify.stopBudgetSeconds 60 deferred every turn; the marker sat at dedd1150, 41 commits behind, so 59 files matched 13 rules per Stop. Hot fix applied locally: marker := gated HEAD.
  • A rule without seconds is never deferrable. Ten of 21 here (PR #197 priced them); 28 of 28 in TheSelectSource; 43 of 43 in SRL, which also had no marker file and a 499 s Stop.
  • In TheSelectSource, rules 0–9 run _verify/smoke.sh without --ci, whose else-branch runs about 18 checks over SSM against the dev web host on every Stop, with ENV="${ENV:-dev}" selecting the target from the ambient environment.
  • Exit 77 (SKIP under smoke.sh) was a hard FAIL under the gate runner.

Components on the branch

Per-rule recordverify_record.py: .crew/.verify-gate.record.json, keyed by rule_key() (canonical JSON of paths, run, env, reach, requiresCleanTree; one function for both flavours via the rule-key subcommand). Written atomically; a corrupt or non-dict file poisons the fingerprint so nothing skips; a failed persist withholds both markers; entries whose rule no longer exists are pruned on sync. Operational notes

  • Hot fix for an existing repository: git rev-parse HEAD > .crew/.verify-verified-at, only if HEAD is a verified state. If it is not, this marks unverified commits as verified and the gate will not look at them again.
  • After upgrading, declare reach on wrapper rules, run /crew:verify --price once, and run /crew:verify --all before a PR because a deferred rule is unverified until it runs.
  • Open sessions load hooks at start; run /reload-plugins to pick up a new version.
