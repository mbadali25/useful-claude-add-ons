6. Lessons Recorded in the Repository

  • Static analysis of shell is an arms race; inspection may only reject.
  • A watcher keyed on a completion marker can spin forever after a process reap; key it on the output going quiet as well.
  • Git Bash's timeout reports 124 and leaves the native Python running; kill by PID.
  • Any multi-commit plugin branch fails the version-set check by construction; squash-merge it.
  • A CHANGELOG union across commits that rewrite one entry keeps stale text; rebuild from main plus the branch's net block.
  • A second session committing to local main while a merge sequence runs means every rebase must target origin/main.
