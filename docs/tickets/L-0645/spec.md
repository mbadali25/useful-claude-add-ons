# L-0645: crew_ghdeploy.py identify - exactly one new workflow run, or could-not-tell          status: spec   risk: high
Split from T-0045. Filed as L-0645.
## Intent
`python3 plugin/crew/hooks/scripts/crew_ghdeploy.py identify --root . --env <E> [--index N]` finds the single workflow run the session's dispatch created and writes its id and URL into `.crew/.ghdeploy/<env>-<N>.json`. It polls every 5 seconds for up to `identifySeconds`. One candidate is the run (exit 0). Two or more, none at the timeout, an unparseable `createdAt`, a missing correlation id, or a state file older than 600 seconds is could-not-tell (exit 3) and names no run.
## Exclusions
- Never picks among candidates: no "newest", no "closest to t0".
- With a correlation id there is no fallback to the time rule.
- No dispatch, no cancel, no re-run. The only `gh` call is `run list`.
- No watching and no write to `.work/PROMOTIONS.md` (L-0646 and L-0647). When L-0647 lands it makes a could-not-tell after a let-through dispatch write a record; here the exit code and the last line carry it.
- No edit to `plugin/crew/tests/sabotage*.py`, promote-gate or autopilot.
## Evidence
Read at origin/main `155fe6d8` on 2026-10-04.
- gh 2.46.0 help: `gh run list` has `-w`, `-b`, `-e`, `-u`, `--created`, `-L` and `--json`. Per the 2026-09-26 measurement its JSON fields include `databaseId`, `createdAt`, `headBranch`, `headSha`, `event`, `status`, `conclusion`, `displayTitle` and `url`, with no actor and no inputs field, which is why the actor is a filter and the correlation id is matched in `displayTitle`. Re-check the field list with `gh run list --json` (no argument prints it) at plan.
- plugin/crew/hooks/scripts/promote-gate.sh:510-511 writes `.crew/.deploy-in-flight` as `<env> <short sha>` when it lets a deploy through: the only on-disk sign that a dispatch was allowed.
- Observed once on 2026-09-26 in the first consumer repository: the run was listed about 2 seconds after the dispatch.
- L-0644 defines the state file's keys.
## Unknowns
- How long a run can take to appear under load. Accepted: `identifySeconds` is configurable from 10 to 900.
- Whether a workflow without a `run-name` can ever show an input in `displayTitle`. It cannot, so `correlationInput` only works for workflows whose `run-name` includes it; the docs say so.
