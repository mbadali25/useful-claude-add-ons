# L-0648: promote-gate reads the github entry - the sha input must be the reviewed HEAD          status: spec   risk: high
Split from T-0045. Filed as L-0648.
## Intent
When a command matches an environment that declares `github` entries, `promote-gate.sh` and `promote-gate.ps1` take the entry whose canonical prefix is the longest substring of the command. If that entry sets `shaInput`, the command must carry `-f|--raw-field|-F|--field <shaInput>=<value>` exactly once, the value must be 40 lowercase hex characters, and it must equal the full HEAD of the tree the gate judges; otherwise the deploy is blocked and the message names which of the three failed. A `github` value that is not an object or a list of objects is exit 4. A `gh workflow run` that names a declared entry's workflow file but matches no environment is blocked: crew cannot tell which environment's preconditions apply.
