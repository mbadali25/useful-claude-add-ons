# Steward - useful-claude-add-ons

`CLAUDE.md` is the policy. This file holds only what the PR loop needs at the
moment it acts. Where the two disagree, `CLAUDE.md` wins and this file is the
bug: fix it here. Cite a section or a path, never a count - a count here is a
second copy that drifts.

## Before any push

- Commit first, then run `python3 scripts/check-marketplace.py`. Its
  version-drift check compares COMMITS: plugin edits still in the worktree pass
  locally and fail CI's `check` job. That is how #263 shipped crew 1.0.62 red.
- A content change under a registered entry needs a version bump, in every
  place that states it (`CLAUDE.md`, "Stop and ask").
- Run the suites `.crew/verify.json` maps to the changed paths. Report which
  ran and which did not (`CLAUDE.md`, "Reporting").
- `plugin/crew/commands/*.md` are line-budgeted
  (`plugin/crew/.budget-allowance.json`). Growth past a file's recorded
  `lines` fails, so edit lines in place.

## Reading a red check

- `check` is `scripts/check-marketplace.py`. It names the fix, and it is this
  PR's.
- A test that asserts elapsed time against a real bound carries
  `@pytest.mark.wallclock` (`plugin/crew/tests/conftest.py`) and runs
  serially. Never loosen the bound, and never skip it.
- "Not this PR's" needs the same failure reproduced on the base commit, in the
  same environment, before it is claimed. Two known cases in a cloud
  container: `skills/doc-builder/scripts/_test/test_render_engine.py::test_a_remote_reference_is_not_fetched_during_conversion`
  (the container's LibreOffice does not fetch), and `_verify/smoke.sh`'s
  PowerShell check where `pwsh` is absent (a missing tool, not a failed check).

## Conventions

- A branch Claude created takes `origin/main` by MERGE, never a rebase. The
  history already does this, and `main` itself is squash- or rebase-merged
  (`Skill-Pipeline.md`).
- `graphify-out/` is regenerated by `graphify update .` only, never by hand
  (`CLAUDE.md`, "Memory").
- After a merge that changes either install script, re-pin the README's
  install URLs to the new SHA (`CLAUDE.md`, "Promotion").
- A PR touching the plugin update path says `scripts/_test/drift-detection.sh`
  did not run in CI, and runs it by hand where the `claude` CLI exists.
